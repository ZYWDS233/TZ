周

别称：大周

皇帝：李安辛（青年女性人类）

国民：人类85%、其他少数民族：15%。

政治：封建君主制、二权分立、威权主义、宗法礼制

外交

大周的外交格局相对简单，仅有因吠罗一个陆上邻国，但大周与因吠罗的关系，贯穿这个王朝的兴衰，亦是朝堂内外常年关注的焦点。

因吠罗

在周人眼中，因吠罗人习俗怪异、开化较晚，被统称为“南蛮”，这种认知带着正统的优越感与鄙夷，两国关系也始终处于“和战交织、势同水火”的状态。

两国常年在边境拉锯，矛盾核心始终围绕着边境领土争端与资源争夺。因吠罗地处大周南部，气候湿热、物产丰饶，其民众虽不善平原决战，却精通山地游击战与丛林突袭，常年派兵袭扰大周南部边境，劫掠村落、抢夺粮食与牲畜，给大周边境百姓带来深重灾难；而大周自视为天朝上国，以正统自居，但将因吠罗视为边境大患，一方面派重兵驻守南部边境，修建防御工事，抵御因吠罗的袭扰，另一方面也时常主动出兵征讨，试图征服这片“南蛮之地”，彰显大国威仪。

两国的交锋，在大周开国初期尤为激烈。大周曾有开国元勋一生战功赫赫，率军深入因吠罗腹地，长驱直入连下七城，险些攻破因吠罗都城。

后来先皇在位时，偏信奸佞谗言，贸然发动南征因吠罗的战争，指挥失当、粮草不济，致使大周百万南征大军几乎全军覆没，国力大损。因吠罗趁机举兵北上，一路势如破竹，直逼大周都城神京城下，若非忽来一场持续数周的暴风雪，令南方的因吠罗人无法适应，加之当时军民上下一心，大周江山危在旦夕。

经此一役，大周对因吠罗的态度愈发复杂，双方皆损失重大，忌惮对方兵力强盛，无力彻底将其征服，也皆无力再发动大规模战争，两国再次陷入对峙僵局，边但境小规模冲突从未停歇。

 

内政

大周虽行君主专制，却并无皇权独断，皇帝以女性身份承统，本是宗法礼制下的无奈之选。

大周以九品十八级官僚体系为治国之本，行军政分离之制，但南征惨败的创伤尚未愈合，百万大军覆没让帝国军力大损，常年边境拉锯又耗空国库。军费开支挤占民生赋税，农政、财税机构竭力修复国力，却始终要优先供给边防，内地民生恢复步履维艰，军政开支成为内政最大的财政包袱。

南征之役后，大周国力凋敝：南部边境因袭扰村落残破、耕织废弛；内地经先皇苛政，百姓疲于赋役，国库储备空虚。新帝登基后，以纾民困、稳民生为内政根基，轻减杂赋、兴修水利、劝课农桑，试图修复国力。虽因财政掣肘，成效尚缓。

 

宗法

大周作为封建王朝，礼制与宗法互为表里、相辅相成：宗法定“血脉正统”，核心是维系皇室传承与宗亲秩序，是皇权合法性的根源；礼制定“尊卑秩序”，覆盖朝堂、皇室、民间、宗教等方方面面，是宗法精神的具体落地，也是威权统治的外在体现。二者共同构成大周统治的精神骨架。

大周的宗法体系，以“嫡长子继承制”为绝对核心，辅以推恩制度、大宗小宗、亲亲尊尊的规则，构建起皇室与天下宗族的传承秩序，拥有不可撼动的权威。按照大周宗法铁律，家产、爵位甚至皇位继承需遵循“嫡长子优先、无嫡立长、无长立贤、无贤立亲”的原则，且明确规定女性不得承统——传承必须归于男性正统血脉，这是上古以来沿袭的宗法底线。

而大周当前的困境，正是宗法体系的现实缺口：先皇当年为夺取皇位、巩固权力，大肆屠戮宗室，弑兄杀弟、清除异己，将自己的近支宗亲斩尽杀绝；加之其晚年苛政失德，民间传言“无子乃天谴”，最终膝下无半子留存，导致皇室大宗彻底断绝，小宗也因屠戮而凋零殆尽。旧太子发动政变失败后自刎，进一步断绝了皇室男性继承的可能。

 

礼制

而如果说宗法是大周统治的内在根基，那么礼制就是外在表象，是将宗法的血脉尊卑转化为可执行、可感知的具体规范，覆盖朝堂、皇室、民间、宗教等每一个角落，既是维系社会秩序的工具，也是彰显皇权威权的方式。大周的礼制体系极为繁琐，等级森严，每一个阶层、每一种身份，都有明确的礼仪规范，不得僭越，否则便是大逆不道，轻则贬官夺爵，重则诛杀满门。

官员之礼

朝堂礼制是礼制体系的核心，直接体现皇权尊卑与官僚等级。大朝会作为大周最高规格的朝堂礼仪，每年正月初一、冬至等重大节日举行，礼仪规范极为严苛：皇帝端坐太和殿龙椅，文武百官按九品十八级的品级排序，正一品官员（中书令、御史大夫、五军都督府大都督）立于殿内前排，依次向后排列，品级越低，站位越靠后；朝见时，百官需按品级行不同礼仪，正一品官员赐座，其他官员则站立；奏事时，需先自报品级姓名，再躬身奏报，不得直视皇帝，更不得打断皇帝讲话。

此外，官员的服饰、车舆、府邸也有严格的礼制规范：正一品官员着紫色蟒袍，佩玉带，车舆用四马牵引，府邸可设九间正房；从一品至正三品着绯色官袍，佩金带，车舆用三马牵引，府邸设七间正房；正四品以下着青色、绿色官袍，佩银带、铜带，车舆用两马或一马牵引，府邸规模依次递减，若有官员僭越服饰、车舆规格，便是触犯礼制，会被御史台弹劾。

皇室之礼

皇室礼制更为繁琐，涵盖皇帝、后妃、宗亲的衣食住行、婚丧嫁娶、诞育册封等所有事务。皇帝的服饰有朝服、祭服、常服之分，朝服用于大朝会，祭服用于太庙祭祀与祭天，常服用于日常理政，每一种服饰的面料、纹样、颜色都有严格规定，龙纹、十二章纹只能由皇帝使用，宗亲与官员不得僭用；后妃的等级也由礼制明确划分，皇后为正宫，以下设贵妃、妃、嫔、贵人等，每一级后妃的服饰、头饰、俸禄、仪仗都有明确区别，不得僭越。

皇室婚丧嫁娶的礼制更为严苛：皇帝大婚、皇后册封，需举行隆重的册封典礼与婚宴，诏告天下，文武百官与地方官员需上表庆贺；先帝驾崩，需举行三年国丧，期间全国禁止宴乐、婚嫁，官员需着丧服。

百姓之礼

民间礼制则是朝堂礼制的延伸，主要规范百姓的婚丧嫁娶、宗族往来、祭祀礼仪，核心是维系民间的尊卑秩序与宗族伦理。百姓婚嫁需遵循父母之命、媒妁之言，不得自由婚配，且需按等级行婚礼。

士绅阶层的婚礼可设三媒六聘，百姓则简化流程，但不得使用士绅阶层的礼仪；丧葬礼仪也按身份等级划分，士绅可设祠堂、立墓碑，百姓则只能简单安葬，不得僭用祠堂规制。民间宗族需遵循宗法礼仪，族长为宗族最高管理者，负责调解宗族矛盾、主持宗族祭祀，宗族子弟需恪守孝道，尊敬长辈，不得忤逆。

此外，礼制还规范了民间的日常言行，比如百姓不得直呼皇帝、宗亲、官员的姓名，需称其官职或爵位；不得穿戴与自身身份不符的服饰，不得使用僭越的器物，这些规范虽繁琐，却有效维系了大周的社会秩序。

宗教之礼

宗教礼制也是大周礼制体系的重要组成部分，由宗正寺专职执掌。大周允许道各种宗教存在，但需遵循礼制规范：所有寺庙、道观、教堂需登记备案，不得私自修建；宗教人员需纳入户籍管理，遵守朝廷律法与礼制，不得干预朝政、蛊惑百姓。

宗教祭祀礼仪需符合皇室礼制，比如教堂、寺庙需在重大节日（如皇帝诞辰、太庙祭祀）举行祈福仪式，不得举行僭越皇权的祭祀活动。礼制对宗教的规范，既体现了大周对宗教的包容，又避免了宗教势力坐大，将宗教纳入威权统治的范畴。

 

附录：光怪陆离的近代史

昔日，旧太子发动政变，皇宫一夜之间被重兵封锁，如今的女帝彼时还是一介无权无势的皇女，被困在深宫之中，沦为任人软禁的阶下囚。危急关头，有太监以匕首在脚底刻字，混出宫去往边塞，这血书辗转抵皇女舅舅手中。国舅立刻率领边军进京勤王，欲以武力平定叛乱。

谁也未曾料到，大军尚未兵临城下，旧太子便已在太和殿拔剑自刎，皇城之内群龙无首，守备力量陷入前所未有的空虚状态。而此时老皇帝，膝下并无皇子继承大统，皇室正统血脉凋零，天下陷入无主的尴尬境地。

按照宗法礼制，无正统皇子便无法名正言顺继位，万般无奈下，加之国舅勤王军队已经兵临城下，老皇帝只能将皇位禅让给女儿——于他而言，将江山传给自家女儿，总好过落入外姓人之手，即便心有不甘，也只能被迫接受这一结局。

可平静的表象之下，暗流从未停歇。如今的太上皇虽退居幕后，却始终暗中筹谋划策，一心想要废掉女帝，重掌江山。

他手中仍握有可观的嫡系力量，只差一个名正言顺的理由——那便是拥有一位皇子。在他眼中，若无皇子，即便夺回皇位，最终依旧要传给女儿，于江山传承毫无意义，因此他只静静等待一位皇子降生，只要皇子出世，便会立刻发动废帝。

但他或许是不知，也或许是不想承认，但天下民心，早已不站在他这边。

太上皇当年为夺皇位弑兄杀弟，造下无边杀孽，在位时又偏信奸佞谗言，致使十余万南征大军全军覆没——他生性凉薄寡恩，对待开国元勋刻薄寡情，昔日辅佐他打下江山的功臣，如今无一善终。世人皆认为，太上皇膝下无子，皆是他恶行招致的报应。

满朝文武与天下百姓，虽心中觉得女子称帝不合古制礼法，但大周皇室早已无半个皇子，太上皇的兄弟也早已被他斩尽杀绝，再加上太上皇本人德行有亏、民心尽失，权衡之下，天下也逐渐接受了女帝登基的事实。

其实太上皇对自己这个女儿并无太深厌恶，甚至偶尔会觉得她处理朝政的手段颇有可取之处，但在权力与江山社稷面前，亲情微不足道。在他心中，女儿终究不是合适的帝王，只因她登基之后，第一时间没有斩草除根、杀光废太子的残余党羽，更没有对自己赶尽杀绝，反而处处礼遇退让。这成了太上皇眼中，当今皇帝最致命的缺陷，也让他废帝的决心，愈发坚定。

 

附录：复杂的九品官僚制

大周以九品十八级构建官僚阶序，形成中枢决策、政令下发、基层执行的三层架构，虽然结构完善、权责清晰，但是往往在要事上陷入流程繁冗的困境。

官员品级分别为：正一品、从一品、正二品、从二品、正三品、从三品、正四品、从四品、正五品、从五品、正六品、从六品、正七品、从七品、正八品、从八品、正九品、从九品。

以下内容展示了大周复杂官员体系的一角。原本正一品官员理应只有中书令（左丞相）、御史大夫（右丞相）和五军都督府大都督（大将军），但特殊的，在新帝登记后，特设了一个额外的正一品职位，即内务大总管。

l 中书省：最高内政机构

n 中书令：正一品，行政总揽，百官之首，即左丞相。

n 中书侍郎：正三品，皇帝内阁，参议朝政。

n 中书舍人：正五品，诏书起草，筛选奏折。

l 御史台：最高监察机构

n 御史大夫：正一品，监察皇帝、总监百官，即右丞相。

n 谏议大夫：正三品，监察百官。

n 巡查御史：正五品到正七品不等，在各个地区巡查百业，典型如巡盐御史、巡农御史等，在神京城外几乎见官大一级，实权极大。

l 五军都督府：最高统兵机构

n 五军都督府大都督：正一品，统领五军都督府，拥有最高统兵权，即大将军。

n 直隶都督：正二品，直隶府最高军官，同时履行神京节度使的职责，统帅神京城的兵马。虽名义上属于五军都督府，但实际独立于该制度，直接负责于皇帝，即天策上将。

n 安南都督：正二品，安南府最高军官，即一等安南将军。

n 河西都督：从二品，河西府最高军官，即一等河西将军。

n 镇北都督：从二品，镇北府最高军官，即一等镇北将军。

n 东海都督：从二品，东海府最高军官，即一等东海将军。

n 节度使：正三品到从四品不等，州单位军官，根据各个州军事水平决定品阶。一般节度使统兵数万甚至数十万，一般封号为二等某某将军。

n 千户：正六品，统兵数千人，一般不会超过万人，即千夫长，一般封号为三等某某将军。

n 百户：从七品，统兵数百人，一般不会超过千人，即百夫长。

n 什长：正九品，统兵数十人，一般不会超过百人，即十夫长。

l 青鸾署：直属皇帝的暴力机构

n 指挥使：正三品，青鸾署最长官，直接对皇帝负责，见官大一级，实权极大。

n 北镇抚司：正四品，专司诏狱，独立于刑部司法体系，拥有自行逮捕、刑讯权。

n 南镇抚司：从四品，主观署内纪律、刑罚和军匠管理。

n 总旗：从六品，直接管理约一千青鸾署兵卫。

n 小旗：正八品，直接管理约一百青鸾署兵卫。

n 力士：从九品，拥有功绩的青鸾署基层成员。

l 太史监：编史机构

n 太史令：正二品，编写国史，对历史和历史记录有绝对权威。

n 大理寺：中央最高审判机构，审理百官犯罪案件及上告神京的重案，以及复核地方死刑案件，重大案件会与刑部、御史台“三司会审”。

u 左署：复核地方死刑案件。

u 右署：外勤调查。

n 鸿胪寺：掌管外交事务及凶丧礼仪，接待外国使节、处理朝贡事宜，并负责蕃客入朝登记、翻译及纠纷调解。

u 典客署：外宾接待。

u 通言署：管理翻译官。

n 司农寺：管理国家仓储和农业，并执行各种农业政策。

u 太仓署：粮食管理。

u 水利署：水利管理。

u 上林署：皇家苑囿。

n 太府寺：掌管国家财政及市场贸易，包括钱帛、珍宝、赋税管理，并负责度量衡标准制定及市场秩序监管。

u 京市署：神京市场监管。

u 国库署：管理国库。

u 常平署：国内物价调控。

l 六部：核心行政机构

为九寺发布行政任务，所有寺有：尚书，正三品，主管本哺；侍郎，正四品，负责下设一司运行；郎中，正五品，部内高管；员外郎，从五品，寺内基层干部，但六部只发布政令但极少亲自执行，故而员外郎多为闲职。

六部官员之间虽品级相同，但实际地位依吏部、兵部最高，刑部、户部次之，而礼部、工部最低。

n 吏部：掌文官铨选、勋爵授予、考课政令，六品以下官员可由吏部直接选授，五品以上需正一品官员提名、皇帝批准。

u 吏部司：负责官员阶品、任免、俸禄及官员身份证明管理。

u 司封司：掌封爵、命妇册封及朝会赐予等级。

u 司勋司：核定官员勋级。

u 考功司：考核官员政绩，主办文科举考试。

n 兵部：掌武官选授、军械管理及军事政令，不直接统兵，仅负责行政事务。

u 兵部司：核定武官阶品、军籍及军事调动，主办武科举考试。

u 职方司：管理边防战略。

u 驾部司：负责驿站、车马及战时后勤运输。

u 库部司：监管武器库藏及仪仗器械。

n 刑部：掌司法政令、案件复核及监狱管理。

u 刑部司：制定律法、复核死刑案件。

u 都官司：管理官婢及罪犯劳役。

u 比部司：审计中央及地方财政收支。

u 司门司：监管关卡通行及违禁物品稽查。

n 户部：掌民政、财政、户籍、赋税。

u 户部司：管理户口、土地、赋役及婚姻继承事务。

u 度支司：统筹全国租赋调配，核定水陆运输成本。

u 金部司：监管国库出纳、度量衡及神京市场交易。

u 仓部司：掌管粮仓储备、官员禄米发放及赈灾。

n 礼部：掌礼仪、祭祀、科举、外交。

u 礼部司：制定礼乐制度、管理学校及皇室丧葬礼仪。

u 祠部司：主管宗教事务及天文历法。

u 膳部司：负责祭祀、宴享的食材供应。

u 主客司：接待外国礼品及外交使节。

n 工部：掌土木工程、屯田水利及手工业，并兼管工匠调配及工程预算。

u 工部司：规划都城建设及宫室营造。

u 屯田司：管理官田、职田分配及屯田事务。

u 虞部司：监管山林川泽、皇家苑囿及渔猎。

u 水部司：负责河道治理、漕运及桥梁修缮。

l 国子监：最高学术机构。

u 祭酒：正四品，国家最高学士，总理国子监。

u 司业：正六品，国子监内部学院的学术主任。

u 监丞：正八品，负责国子监内部学院的具体授课。

l 钦天监：气象与玄学机构。

u 监正：正五品，主职为占卜。

u 官正：从六品至从九品不等，观测天象、制定历法。
